# Licence

The 178 YAML type files in this directory, together with `schema.yaml`,
`schema.json`, `validate.py` and `README.md`, are covered by the repository's
[Apache License 2.0](../LICENSE), like every other file here. Attribution is
in [`NOTICE`](../NOTICE).

They are hand-written clinical prose rather than code: descriptions of what
each HealthKit type measures, how it is interpreted, typical and clinically
notable ranges, and the sources those came from. Apache-2.0 covers prose
perfectly well — the permissions and the attribution requirement read the
same — it is simply not the conventional licence for it. If the copyright
holder would rather use the usual one for text, **CC BY 4.0** is the
customary choice for a corpus like this, and moving to it is their call
alone.

Nothing here is medical advice. Every file's `sources` block cites where its
clinical claims come from; check those before relying on a range.
